# Orchard

**[Orchard](https://orchard.andon.dev/)** is **Docker Desktop** alternative, a native macOS app for Apple's container tooling - manage containers and machines, bridge local AI models into them, and run agents in isolated sandboxes, all without dropping to the CLI

## Features

- Container management, Image management, Container management
- Kubernetes clusters
- Local AI & sandboxes
- Command palette
- Networks & DNS
- Multi-pane logs

## Install

```shell
brew install orchard
```
